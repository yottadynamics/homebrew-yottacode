# yottacode Homebrew Tap

This is the official Homebrew tap for [yottacode](https://yottacode.ai), an AI coding agent for the terminal.

## Install

```bash
brew install yottadynamics/yottacode/yottacode
```

The formula installs the latest stable macOS release for Apple silicon or Intel Macs. It downloads the signed release archive from the yottacode GitHub releases page and verifies its SHA-256 checksum.

## Upgrade

```bash
brew update
brew upgrade yottacode
```

## Uninstall

```bash
brew uninstall yottacode
```

The formula in `Formula/yottacode.rb` is generated by the yottacode release workflow for stable releases. Pre-release versions are not published to this tap.
